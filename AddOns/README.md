# AddOns 目录索引

| 插件 | 功能 | 命令 |
|---|---|---|
| [TipPrice](TipPrice/README.md) | 物品提示显示单价 / 一组价 / 当前数量价 | 无（自动生效） |
| [EquipCompare](EquipCompare/README.md) | 装备对比（背包/商人/回购/任务/制造/训练师） | `/ec test` |
| [UnitEnhance](UnitEnhance/README.md) | 头像增强：血量法力数值面板 | `/ue` |
| [ToTPlus](ToTPlus/README.md) | 目标链显示（可点击切换目标） | `/tot` |
| [MinimapBag](MinimapBag/README.md) | 小地图按钮收纳 | `/mmb open\|close\|rescan\|restore` |
| [CDTimers](CDTimers/README.md) | 超出射程的技能图标变红 | `/rc on\|off` |
| [DBBrowser](DBBrowser/README.md) | 物品/任务/NPC 数据库查询 | `/wdb` 或 `/dbrowser` |
| [WowCNInput](WowCNInput/README.md) | 中文输入法（第三方 GPL） | `Ctrl+Space` |

## 安装

把整个文件夹复制到 `Interface\AddOns\`，然后**完整重启客户端**。
