# UnitEnhance —— 1.12 原生头像增强

参照 335 客户端里的 **EN_UnitFrames（Enigma Unit Frames v3.1.1）** 写的原生版：
UI 布局与选项结构照搬，功能按 1.12 的能力取舍。

## 为什么不是移植 EN

EN 有 1775 行，依赖 `RegisterUnitWatch`(8 处)、`hooksecurefunc`(6)、`UnitFrame_*`(6)、
`UnitPower`(3)、`C_*`(2) 和 `Duowan` 框架；GitHub 上也没有它的 1.12 版本
（只有一个 8.0 仓库和一个空仓库）。故按它的界面与功能重写。

## 界面（实测）

玩家框：

```
        Admins
100% ───────── 212/212     ← 血条：左百分比、右数值
100% ───────── 260/260     ← 法力条
   2213/6500 (+122)        ← 经验条（含双倍经验）
```

设置面板（`/ue` 打开），与 EN 的选项一一对应：

```
头像增强                              [X]
☑ 开启玩家头像扩展
☑     显示经验条
☑ 开启目标头像扩展
☑     显示百分比
☑ 显示目标的目标
☑ 开启队友头像扩展
☑     显示队友目标
```

## 功能对照表

| EN 的选项 | 本插件 | 说明 |
|---|---|---|
| 开启玩家头像扩展 | ✅ | 血/蓝条左右两侧数值与百分比 |
| 显示经验条 | ✅ | 玩家框下方经验条 + `当前/上限 (+双倍)` |
| 开启目标头像扩展 | ✅ | 目标框同样显示 |
| 显示百分比 | ✅ | 关掉只留数值 |
| 显示目标的目标 | ✅ | ToT 血条中央显示百分比 |
| 显示目标的目标的目标 | ❌ | 1.12 只有 `targettarget`，没有三级目标 |
| 显示焦点头像 | ❌ | **1.12 客户端没有 focus 单位**，按你的要求跳过 |
| 开启队友头像扩展 | ✅ | 小队 1~4 血条数值 + 百分比 |
| 显示队友目标 | ✅ | 小队成员的目标，下方小血条 + 百分比 |
| 显示队友 BUFF | ❌ | 需要独立 buff 扫描，暂未做 |

## 命令

```
/ue        打开/关闭设置面板
/ue on     全部开启
/ue off    关闭玩家/目标/小队显示
```

设置存于 `UnitEnhanceDB.opts`。

## 技术要点（1.12 踩坑）

### 1. 状态条对象名

从客户端 `interface.MPQ` 的 FrameXML 里确认：

| 框架 | 血条 | 法力条 |
|---|---|---|
| 玩家 | `PlayerFrameHealthBar` | `PlayerFrameManaBar` |
| 目标 | `TargetFrameHealthBar` | `TargetFrameManaBar` |
| 目标的目标 | `TargetofTargetHealthBar` | — |
| 宠物 | `PetFrameHealthBar` | `PetFrameManaBar` |
| 小队 N | `PartyMemberFrame{N}HealthBar` | — |

### 2. OnUpdate 拿不到 elapsed

`function(self, elapsed)` 里 `elapsed` 是 nil，时间累加永远到不了阈值，文字不刷新。
改成**帧计数节流**（每 5 帧）后正常。TipPrice 也踩过同一个坑。

### 3. 中文字体

`GameFontNormal` 不含汉字，所有文字统一 `SetFont("Fonts\\FZLBJW.TTF", size)`，
否则显示方块。

## 界面布局（v3，对照 EN 红框

EN 的数值不在血条里，而是在血条右侧的**深色扩展面板**里竖排显示。
v3 照此实现：

```
玩家框                                  目标框
[头像][Admins        ]  ┌──────────┐   [目标条   ]  ┌──────────┐
      [100% ▓▓▓▓▓▓▓▓▓]  │ 212/212  │   [100% ▓▓▓]  │ 212/212  │
      [100% ▓▓▓▓▓▓▓▓▓]  │ 100%     │   [100% ▓▓▓]  │ 100%     │
      └── 2213/4500 ──┘  │ 260/260  │              │ 260/260  │
                         └──────────┘              └──────────┘
```

- 血条内：左侧百分比（绿色 HP / 蓝色 MP）
- 扩展面板：生命数值 / 百分比 / 法力数值，深色底 + 细边框
- 目标框的面板放在其血条下方（右侧是头像，放右边会挡住）
- 目标框整体右移，给玩家框的面板腾出位置（`TargetFrame` 锚定到 `PlayerFrame +340`）

## 踩坑记录（面板相关）

| 现象 | 原因 | 解决 |
|---|---|---|
| 面板有文字没黑底 | 子框架 frame level 与父框架相同，背景被父框架贴图盖住 | `SetFrameLevel(parent:GetFrameLevel() + 5)` |
| 目标框面板挡住头像 | 1.12 的目标框头像在右侧 | 面板改挂到法力条下方，并右移 22px 避开 ToT 图标 |
| 玩家面板压住目标框 | 两个框默认只隔约 70px | 把目标框重新锚定到 `PlayerFrame` 右侧 340 |

### v4：面板位置调整

玩家框的面板在**其血条右侧**，目标框的面板放在**两个框之间的空隙**（目标框血条左侧），
两者都和三行数值对齐，视觉上像一条连续的数值带：

```
[玩家框] [212/212][空隙][212/212] [目标框]
         [100%   ]      [100%   ]
         [260/260]      [260/260]
```

目标框只在**首次安装**时右移一次（`UnitEnhanceDB.targetPinned`），
之后不再干预，可以自由拖动。
