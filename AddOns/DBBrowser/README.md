# DBBrowser —— 游戏内数据库查询插件（1.12）

## 一、用途

在游戏里直接查**物品 / 任务 / 生物**，不用切窗口、不用浏览器。

- 命令：`/db` 打开或关闭
- 数据来源：本服 `twptr_world` 库（导出成 Lua，离线可用）
- 数据量：物品 20,700 / 任务 5,875 / 生物 12,513（含中文名，来自 locales_* 表的 *_loc4）

## 二、界面

| 区域 | 说明 |
|---|---|
| 顶部标签 | 物品 / 任务 / 生物，点一下切换 |
| 输入框 | 输入英文名或数字 ID，回车搜索 |
| 结果区 | 14 行/页，物品按品质着色 |
| 底部 | 上一页 / 下一页 + 结果统计 |
| 右上 X | 关闭面板（面板可拖动） |
| ESC | 关闭面板并释放键盘焦点（输入框有焦点时，聊天命令会被吃掉） |

物品行显示：ID、名称、物品等级、需要等级
任务行显示：ID、任务名、任务等级
生物行显示：ID、名称、等级范围

## 三、安装位置

```
Interface\AddOns\DBBrowser\
├─ DBBrowser.toc          （接口 11200）
├─ DBBrowser.lua          （界面 + 搜索逻辑）
└─ DBBrowser_Data.lua     （数据，1.2 MB）
```

备份副本：`deploy\DBBrowser插件\`

## 四、搜索说明

- **中英文都能搜**：
  - 中文：`短剑`（45 条）、`狼`（任务 38 条）
  - 英文：`sword`、`wolf`、`belt`
  - 数字 ID：`25`、`7241`
- 结果优先显示中文名（取自 `locales_item.name_loc4` / `locales_quest.Title_loc4` / `locales_creature.name_loc4`），
  没有中文翻译的条目回退显示英文名
- 结果上限 3000 条（防止卡顿），超出时只显示前 3000

## 五、数据更新

服务器数据库有变动后，重新导出一份即可：

```bat
python deploy\tools\export_db_addon.py
```

脚本会直接重写 `DBBrowser_Data.lua`，重启客户端生效。

## 六、开发中踩的坑（1.12 特有）

| 现象 | 原因 | 解决 |
|---|---|---|
| 插件不出现在插件列表 | TOC 里中文 Notes 行把换行吞了 | TOC 改成纯 ASCII |
| `unexpected symbol near '|'` | Lua 5.0 **不支持** `[==[ ]==]` 长字符串（5.1 才有） | 改用 `[[ ]]`，并确保数据里没有 `]]` |
| `SetText(): Font not set` | 客户端没有 `Fonts\ARKai_T.ttf`，`SetFont` 失败 | 改用内置字体对象 `GameFontNormal` 系列，不依赖字体文件 |
| `'=' expected near 'label'` | 批量删除 `SetFont` 时留下了孤立的标识符行 | 清理孤立行 |

## 七、已知限制

1. 只读查询，不能改数据
2. 没有物品图标（1.12 取图标需要 DBC 查询，插件拿不到）
   中文名来自服务端 locales 表；少数条目（约 3%）没有中文翻译，显示英文
3. 面板位置不保存（每次打开在屏幕中央）
4. 打开面板瞬间如果正好在加载，数据解析会占 1~2 秒（一次性）
